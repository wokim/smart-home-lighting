# 세미나 영상 촬영 가이드

## 파일명 규약

영상 파일을 다음 이름으로 제공하시면 됩니다. 같은 이름의 `.jpg`는 재생 실패 시 대체할 포스터 이미지입니다.

- `opening-scenes.mp4` — 거실 씬 스위치 (취침·파티 모드 전환, 수십 개 조명 일괄 제어)
- `stairs-sensor.mp4` — 계단 센서 (스르륵 점등, 시간 경과 후 감광, 재감지 시 복귀)
- `bad-dimming.mp4` — 나쁜 예 (팝콘현상, 끊기는 디밍, low-end 문제 등)

## 촬영 규칙

### 기술 사항
- **가로 방향**, 1080p 30fps로 촬영
- **편집 없이** 길게 찍고 앞뒤만 자르기

### 필수 요건
- **폰을 고정한다** — 손으로 들면 밝기 변화가 흔들림에 묻힌다
- **노출과 화이트밸런스를 잠근다** — 자동으로 두면 카메라가 밝기 변화를 상쇄해서 화면상 아무 일도 일어나지 않은 것처럼 보인다. 실패의 대부분이 이것이다
- **손이 스위치를 누르는 장면을 프레임에 넣는다** — 버튼과 조명이 한 화면에 있어야 인과가 보인다

### 참고
폰 촬영 품질로 충분합니다. 이 청중에게는 스톡 영상보다 실제 집을 찍은 화면이 더 신뢰를 줍니다.

**PWM 밴딩은 버그가 아니라 소재입니다.** 셔터스피드에 따라 화면에 가로줄이 생기는데, 이것은 플리커를 설명하는 가장 좋은 예시가 됩니다. 나쁜 조명을 일부러 밴딩이 보이게 찍는 것도 괜찮습니다.

## 재생 처리

- 클립당 10~20초, `muted autoplay loop playsinline`으로 자동 재생·반복
- 재생 실패에 대비해 대표 프레임 스틸을 백업으로 깔아뒀습니다 (같은 이름 `.jpg`)
- 영상 파일은 Git LFS로 관리되므로, 영상 없이 덱만 클론해도 슬라이드가 깨지지 않습니다
